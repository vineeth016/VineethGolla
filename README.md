**What I build**

I work on backend systems where performance, reliability, and clean service boundaries matter.

My strongest work is in Java and Spring, with Kafka and Flink for event-driven processing, Redis and SQL for data access, Solr for search, and AWS and Kubernetes for production delivery.

I care about the parts that usually decide whether a backend system holds up in production: retries, timeouts, duplicate requests, backpressure, caching, failure recovery, observability, and clear ownership between services.

**How I approach backend work**

A request working once is not enough. I think about what happens when it is retried, duplicated, delayed, partially fails, or hits a slow dependency.

I prefer systems with simple boundaries, predictable data flow, useful logs, safe failure handling, and code another engineer can understand without needing a long explanation.
